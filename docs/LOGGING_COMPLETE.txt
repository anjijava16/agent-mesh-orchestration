📊 HOW TO VIEW LOGS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Use the Log Viewer Script:
──────────────────────────────────────────────────────────────────

# Watch all logs (real-time)
./view-logs.sh all -f

# Watch specific service logs
./view-logs.sh backend -f          # Backend logs
./view-logs.sh ingestion -f        # Ingestion logs
./view-logs.sh celery -f           # Celery logs
./view-logs.sh mcp-docs -f         # MCP Documents logs
./view-logs.sh mcp-search -f       # MCP Search logs
./view-logs.sh mcp-memory -f       # MCP Memory logs

# View last N lines
./view-logs.sh backend -n 100      # Last 100 lines
./view-logs.sh celery -n 50        # Last 50 lines

# List all log files
./view-logs.sh -l

# Help
./view-logs.sh --help


Manual Log Viewing:
──────────────────────────────────────────────────────────────────

# Watch all today's logs
tail -f logs/*_$(date +%Y%m%d)*.log

# Watch specific service
tail -f logs/backend_*.log
tail -f logs/celery_*.log

# View last lines
tail -n 100 logs/ingestion_*.log

# Search for errors
grep -i "error" logs/*.log

# Search with context
grep -C 3 "failed" logs/celery_*.log
